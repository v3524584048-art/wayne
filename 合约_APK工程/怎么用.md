# 把网页打包成手机 App（APK）

这个工程做的事只有一件：用一个安卓外壳把你的网页装起来，
外壳可以直接指定**状态栏纯白、图标深色**——这正是浏览器快捷方式做不到的那一点。
另外桌面图标、App 名称也都由外壳自己决定，不再依赖 Chrome。

网页本身仍然从网上加载，所以**以后我改了页面，你只要重新拖 html 到 Netlify，
App 里就是最新的，不用重新打包。**

---

## 第一步：确认网址

打开 `app/src/main/java/com/wayne/okxsim/MainActivity.java`，
第 18 行左右：

```java
private static final String URL = "https://rois-074079.netlify.app/";
```

我按你截图里的网址填好了。如果你换了新站点，把引号里的地址改掉即可，其他一律不用动。

---

## 第二步：让 GitHub 帮你编译（不用装任何软件）

1. 注册 / 登录 GitHub，点右上角 `+` → `New repository`，名字随便（比如 `okxsim-app`），
   选 **Public**，创建。
2. 在新仓库页面点 `uploading an existing file`，
   把这个文件夹里的**所有内容**（包含 `.github` 这个文件夹）拖进去，`Commit changes`。
   - 注意：要传的是文件夹**里面**的东西，不要把整个文件夹当一个整体传到子目录里。
3. 传完后点仓库上方的 **Actions** 标签，会看到一条正在跑的任务「打包 APK」，等 3～5 分钟。
4. 变成绿色对勾后点进去，页面最下面 **Artifacts** 里有个 `apk`，下载下来，
   解压得到 `app-debug.apk`。
5. 把这个 apk 传到手机上安装（手机会提示「未知来源」，允许即可）。

以后想改网址或图标，改完文件再 commit 一次，Actions 会自动重新打包。

---

## 说明

- 这是 debug 签名的包，自己用完全没问题，只是不能上架应用商店。
- 折叠屏展开/折叠时页面不会重新加载（`configChanges` 已经写全）。
- 系统字体大小不会影响页面（`setTextZoom(100)`），保证界面比例和交易所一致。
- 返回键 = 网页后退，退到头再按才退出。
